# Stage I Visualization Evidence

This directory retains one compact, reproducible visualization smoke test.

The tracked `stage1_demo.mp4` was generated with:

```bash
./scripts/visualize_stage1.sh \
  --render video \
  --policy scripted \
  --seed 44 \
  --max-steps 500 \
  --output-dir results/visualization
```

The video shows the public hazard-lidar distance, fixed monitor thresholds,
warning trigger, deadline countdown, on-time recovery, native cost, and STL cost
beside the simulator frames. `summary.json` records the exact run statistics and
software versions.

The ignored `trajectory.csv` can be regenerated by the command above. The
scripted controller uses privileged hazard positions only to create a visible
approach/escape sequence; the monitor still consumes only public lidar data.
This artifact is not an RL policy result.
